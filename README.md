# Orbit AI

為學生設計的輕量級瀏覽器課表儀表板。一目瞭然地查看您的課程表——下課時間、下一節課程、科目與教師。

## 🚀 快速開始

**[打開 Orbit AI](https://jaypengx-collab.github.io/Orbit/)**

完全免費，無需安裝、無需帳戶、無需登入。支援桌面和行動裝置。

---

## ✨ 功能特色

### 首頁儀表板
- **實時顯示** — 清楚看到下課時間和下一節課程
- **課程詳情** — 即時查看科目、教師、教室和每週節數
- **倒數活動輪播** — 在首頁左右滑動切換考試和重要截止日期

### 完整課表管理
- **科目與教師** — 新增並管理您的所有科目和教師
- **節次時間** — 自訂每堂課的開始和結束時間
- **特殊時段** — 設定午餐、集會等特殊時段
- **排課系統** — 逐日編輯您的每週課表
- **雙週科目支援** — 單週和雙週課程可用「／」分隔（例：國文／公民）

### 高級功能
- **單雙週對調** — 自動處理不同週次的課表輪換
- **時間模擬** — 輸入任意時間查看該時刻的課表
- **倒數活動** — 新增考試、作業、報告等重要事件，首頁自動顯示倒數
- **樣式工具** — 在深色和淺色主題間自由切換，自訂顏色配置
- **匯入 / 匯出** — 完整備份和恢復您的課表設定
- **圖片匯入（AI 辨識）** — 上傳課表照片，AI 自動判讀整張照片內容，快速產出課程、教師與節次資料

## 📋 使用指南

### 第一次設定

#### 步驟 1：新增科目與教師
1. 點擊頂部工具欄的**編輯課表**按鈕
2. 在「科目與教師」區段點擊**新增**
3. 輸入科目名稱（例：國文）和教師名稱（例：李老師）
4. 支援雙週科目：用「／」分隔兩週不同的科目（例：國文／公民）

#### 步驟 2：設定節次時間
1. 點擊「課表」區段中的**節次**按鈕
2. 新增每一節課的時間範圍（例：08:00 - 08:50 為第一節）
3. 最多支援 15 節課

#### 步驟 3：設定特殊時段（可選）
1. 點擊「課表」區段中的**時段**按鈕
2. 新增特殊時段名稱和時間範圍（例：午餐 12:30 - 13:30）
3. 特殊時段會在首頁顯示

#### 步驟 4：排課
1. 點擊「排課」部分選擇星期（一到五）
2. 為每一節課選擇科目和教師
3. 點擊**套用並完成**保存排課

#### 步驟 5：新增倒數活動（可選）
1. 點擊「倒數活動」區段中的**新增倒數**
2. 輸入活動名稱（例：期中考）和日期
3. 首頁會顯示第一個倒數活動，可滑動切換其他倒數

### 快速操作

**編輯課表**（🖊️ 按鈕）
- 進入編輯模式，修改您的課表設定

**時間模擬**（⏱️ 按鈕）
- 輸入任意時間，模擬該時刻的課表顯示
- 用於檢視特定時段的課程安排

**樣式工具**（🎨 按鈕）
- 切換深色/淺色主題
- 自訂主題顏色

## 💾 備份和恢復

### 匯出課表備份
1. 點擊**編輯課表**
2. 找到「匯入 / 匯出」區段
3. 點擊**匯出**按鈕
4. 複製完整備份文字（包含 BEGIN 和 END 標記）
5. 將文字粘貼到安全的地方（筆記、郵件等）

### 匯入課表備份
1. 點擊**編輯課表**
2. 找到「匯入 / 匯出」區段
3. 在文字框內貼上完整的備份文字
4. 點擊**匯入**按鈕
5. 您的課表設定會被恢復

## 🤖 AI 圖片匯入

使用 AI 快速匯入課表照片：

1. 點擊**編輯課表**
2. 找到「匯入 / 匯出」區段中的「圖片匯入」
3. 點擊**選擇圖片**上傳課表照片
4. 預覽圖片確認無誤
5. 點擊**匯入**按鈕，AI 會自動判讀整張照片中的課表內容
6. 在「辨識結果與匯入預覽」區段檢查 AI 辨識結果
7. 如有需要，手動調整節次時間、課程和課表指派
8. 點擊**確認並匯入**完成

**提示：** AI 會自動提取課程、教師和節次資料，您可以在匯入預覽中檢查和修改。

## 📱 跨裝置使用

1. 在電腦上建立並備份課表
2. 點擊**編輯課表** → **匯出**複製備份文字

5. 您的課表立即同步到手機

## 🎯 常見問題

**Q：我的數據會丟失嗎？**
A：不會。您的課表自動儲存在瀏覽器本地。即使關閉應用，下次打開時數據仍然存在。建議定期**匯出**備份以防萬一。

**Q：可以在多個裝置間同步嗎？**
A：可以。使用**匯入 / 匯出**功能手動同步。複製備份文字後在其他裝置上匯入即可。

**Q：如何刪除所有數據？**
A：清除瀏覽器快取和 Cookie，或在設定中清除網站數據即可。

**Q：AI 圖片匯入有什麼要求？**
A：上傳清晰的課表照片。照片應包含課程、教師和時間資訊。AI 會自動判讀內容。

**Q：支援多少節課？**
A：最多支援 15 節課。

**Q：可以設定周末課程嗎？**
A：目前支援星期一至五。
